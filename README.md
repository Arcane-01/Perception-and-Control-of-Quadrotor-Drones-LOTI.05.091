# Perception and Control of Quadrotor Drones (LOTI.05.091)

Repository associated with the course **Perception and Control of Quadrotor Drones (LOTI.05.091)**.

---

## Instructions

1. Make sure that you have [PyFlyt](https://github.com/jjshoots/PyFlyt) installed.

2. Clone this repository:

	```bash
	git clone https://github.com/Arcane-01/Perception-and-Control-of-Quadrotor-Drones-LOTI.05.091.git <dir_name>

	cd <dir_name>
	```

3. Run the example template:

	```bash
	python3 pyflyt_template.py
	```
